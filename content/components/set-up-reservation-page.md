---
title: "Set up Reservation page"
description: "1. Install and activate "Five Star Restaurant Reservations" plugin in Dashboard > Dine > Install Plugins."
---

1. Install and activate "Five Star Restaurant Reservations" plugin in **Dashboard > Dine > Install Plugins**.
2. Configure your reservation form in Dashboard > Bookings > Settings
3. Create new page, name it Reservation, Booking.. whatever you want.
4. Edit it in Elementor. Add **[Dine] Form** element into it and choose to display **Reservation form**.
5. Go to Dashboard > Appearance > Menus > add this page “Reservation” into your menu.
