There's 2 methods to set up Blog.

### Set up Blog Using Elementor

This often is the way we set up blog in Dine demos.

1. Create new page, name it Blog, Journal, News.. whatever you want.
2. Edit it in Elementor. Add **[Dine] Posts** element into it. So it shows your recent posts now.
3. Go to Dashboard > Appearance > Menus > add this page "Blog" into your menu.

### Set up Blog using WP option

This is another option but we do not use this option in Dine demos.

1. Create a new page, name it "Blog".
2. Go to Dashboard > Settings > Reading and choose your newly added page "Blog" for the "Posts page" there.
3. Go to Dashboard > Appearance > Menus > add this page "Blog" into your menu.

By this way, we don't need to add content to your blog page. The system does it automatically. However, while it does it automatically it also takes the flexibility away from your blog. That's why we often used the previous method to build the blog.
