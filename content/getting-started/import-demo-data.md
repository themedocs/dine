We assume that you have installed WordPress and Dine theme already. Otherwise, please [read this article](/dine/getting-started/install/) for installing the theme first.

#### Step 1: Install Plugins

Make sure you have installed and enabled following plugins:

- **Elementor**: *required*
- **(Dine) Elementor Addons**: *required*
- **Contact Form 7**: *optional*, but it's used to build the contact page
- **Restaurant Reservation**: *optional*
- **WP Google Maps**: *optional*

If you haven't installed Elementor or (Dine) Elementor Addons, please go to **Dashboard > Dine > Install Plugins** to install them.

#### **Step 2**: Import Content

![](/dine/assets/Screen-Shot-2022-08-03-at-19.17.57.png)

Please go to **Dashboard > Dine > Import Demo**.

Choose your demo your want to import then hit **INSTALL DEMO**.

![](/dine/assets/Screen-Shot-2022-08-03-at-19.26.48-1024x560.png)

*Choose **Yes, Import!***

![](/dine/assets/Screen-Shot-2022-08-03-at-19.27.02.png)

*During the importing process, you'll see this screen. Just wait for few minutes.*

![](/dine/assets/Screen-Shot-2022-08-03-at-19.30.12-1024x585.png)

*You'll see a message like this after it finish importing demo content.*

#### **Step 3**: Import Elementor Style

After importing the content, you'll see your site looking like this:

![](/dine/assets/compare.jpg)

It's because of the lack of Elementor Style. That's why we need the last step: import Elementor style.

![](/dine/assets/Screen-Shot-2022-08-03-at-19.44.21-1024x719.png)

**Step 3.1**: Go to **Dashboard > Elementor > Tools > Import/Export Kit > Start Import**.

**Step 3.2**: Depending on which demo you chose, please download following Elementor style file:

- [Dining](/dine/assets/dining-elementor-style-kit.zip)
- [Asian Food](/dine/assets/asian-food-elementor-style-kit.zip)
- [Robusta](/dine/assets/robusta-elementor-style-kit.zip)

![](/dine/assets/Screen-Shot-2022-08-03-at-19.45.57-1024x776.png)

then click **Select File** and upload it.

Then just continue hitting the green button, don't do anything else.

![](/dine/assets/Screen-Shot-2022-08-03-at-19.47.12.png)

*Click **Next** at the bottom-right corner*

![](/dine/assets/Screen-Shot-2022-08-03-at-19.47.46.png)

*Click **Import** at the bottom-right corner*

Then you'll see following screen. Now your site is 100% same as demo.

![](/dine/assets/Screen-Shot-2022-08-03-at-19.49.52.png)

That's all. Now you can hit the green **Close** button and start customizing your site.
