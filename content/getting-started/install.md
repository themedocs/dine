Before installing Dine theme, you need to install WordPress. Please follow [this guide](https://wordpress.org/support/article/how-to-install-wordpress/) for installing WordPress.

#### **Step 1**: Download Theme

![](/dine/assets/Screen-Shot-2022-08-03-at-18.10.58.png)

Visit [your download page on Themeforest](https://themeforest.net/downloads) then click to download the installable WordPress file, you'll get a **zip** file.

#### **Step 2**: Install Theme

![](/dine/assets/Screen-Shot-2022-08-03-at-18.13.32.png)

Go to your site **Dashboard > Appearance > Themes** and click **Add New**, then choose **Upload Theme**.

![](/dine/assets/Screen-Shot-2022-08-03-at-18.14.32.png)

Upload your zip file and hit **Install Now**, then hit **Activate**.

![](/dine/assets/Screen-Shot-2022-08-03-at-18.20.27.png)

#### Step 3: Install Plugins

![](/dine/assets/Screen-Shot-2022-08-03-at-18.24.09-1024x629.png)

To make Dine work as expected and express its full power, you'll need to install additional plugins.

Please go to to **Dashboard > Dine > Install Plugins**, you'll see a list of plugins. Two essential plugins you must install are: **Elementor** and **(Dine) Elementor Addons**.

#### Step 4: Import Demo

This step is optional. If you want to build everything yourself, you can start customizing your website now. Otherwise, you can import any demo your want.

To import demo content, please read [this article](/dine/getting-started/import-demo-data/).
