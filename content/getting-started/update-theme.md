To update theme, please follow following steps:

**Step 1**: Go to [download page](https://themeforest.net/downloads) and download the theme file latest version. Please choose "Installable WordPress" file only.

![](/dine/assets/Screen-Shot-2022-08-29-at-10.37.50-1024x336.png)

**Step 2**: Go to your site **Dashboard > Appearance > Themes > Add New > Upload Theme** and upload your zip file you have just downloaded. This process is really like how you install a new theme.

![](/dine/assets/Screen-Shot-2022-08-29-at-10.40.27-1024x616.png)

**Step 3**: You'll see a screen and being asked like this:

![](/dine/assets/Screen-Shot-2022-08-29-at-10.42.12-1024x559.png)

*Choose **Replace active with uploaded***

Now you have the Dine theme in latest version.

**Step 4**: Update necessary plugins. After updating the theme, when you go back to your Dashboard you might see a message like this:

![](/dine/assets/Screen-Shot-2022-08-29-at-10.43.57-1024x271.png)

Please hit to "Begin updating plugins". You can also go to **Dashboard > Dine > Install Plugins** if you missed the link.

![](/dine/assets/Screen-Shot-2022-08-29-at-10.46.09-1024x444.png)

There you'll see a list of plugins that need to update. Hit "update" link to update them to the latest version. **Note**: There's 2 plugins we highly recommend you always to update to the latest version: **Elementor** and **Dine Elementor Addons**. If you don't see the plugin there, it means that plugin has been in the latest version.

![](/dine/assets/Screen-Shot-2022-08-29-at-10.49.47-1024x406.png)
