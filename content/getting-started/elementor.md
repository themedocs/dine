Dine uses Elementor to build pages so It's mandatory to install and activate Elementor.

Plus, Dine adds a few number of Elementor addons via the plugin Dine Elementor Addons, so that you need to install that plugin too to let Dine expresses its full power.

To install those plugins, please go to **Dashboard > Dine > Install Plugins**.

If you are not familar with Elementor, please visit [their documentation](https://elementor.com/help/how-to-use-elementor/) (tutorial with videos)
